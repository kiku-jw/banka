# Implementation notes

## Editorial decisions

- Preserve stage, category, and mode slots to avoid changing game pacing.
- Replace the idea, not merely polish the sentence, when the original premise
  was abstract or over-designed.
- Use short direct wording and familiar subjects.
- Preserve the eleven explicitly approved prompts verbatim.

## Delivered editorial changes

- Replaced 56 abstract, faceless, meta, or over-designed prompts in place.
- Added more direct questions about childhood, work, friendship, Bible
  characters, service preferences, and everyday skills.
- Simplified performance cards into scenes that are immediately visible and
  easy to act.
- Added an exact regression fixture for all 56 rejected prompts and all 11
  approved prompts.

## Adversarial review

The first review found five replacements that still relied on vague
improvisation or generic ministry discussion. They were replaced with concrete
choices or actions. The second pass found no blocking issues. The residual risk
is subjective taste during live play, which remains covered by per-question
feedback.
